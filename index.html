Install Sales Rep Enablement

Add Audix CRM to your iPhone Home Screen.

1. Tap the Safari Share button.
2. Select Add to Home Screen.
3. Turn Open as Web App OFF if shown.
4. Name it Audix CRM.
5. Tap Add.
6. Return to Safari.
7. Select your name below.
8. Tap Complete CRM Installation.
